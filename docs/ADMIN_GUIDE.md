# RunDay Admin Guide

## 🔧 Admin Dashboard Overview

The RunDay Admin platform provides comprehensive tools for managing running events, participants, and results. This guide will help you make the most of the admin features.

## 🚀 Getting Started

### Admin Access

1. **Access Admin Portal**: Go to [https://run-day-admin.vercel.app](https://run-day-admin.vercel.app)
2. **Admin Account**: Use your admin credentials (contact system administrator)
3. **Dashboard Overview**: View event statistics and recent activity

### Admin Dashboard Features

Your admin dashboard displays:
- **Event Overview**: Total events, active registrations, completed events
- **Recent Activity**: Latest registrations and participant actions
- **Quick Actions**: Create new events, manage participants
- **Statistics**: Real-time metrics and performance data

## 📅 Event Management

### Creating New Events

1. **Navigate to Events**: Click "Events" in the sidebar
2. **Create Event**: Click "Create New Event" button
3. **Fill Event Details**:
   - **Basic Info**: Name, description, date, time
   - **Location**: Venue address and details
   - **Registration**: Start/end dates, participant limits
   - **Event Settings**: Distance, category, pricing

4. **Save and Publish**: Review details and activate event

### Event Information Required

**Essential Details:**
- Event name and description
- Event date and start time  
- Registration period (start/end dates)
- Maximum participants (if limited)
- Event distance and category
- Location/venue information

**Optional Settings:**
- Registration fee (if applicable)
- Special requirements or notes
- Event image or logo
- Additional contact information

### Managing Existing Events

#### Edit Event Details
1. **Find Event**: Use search or browse event list
2. **Edit Event**: Click edit icon on event card
3. **Update Information**: Modify any event details
4. **Save Changes**: Confirm updates

#### Duplicate Events
- **Quick Copy**: Click duplicate icon to create similar event
- **Smart Defaults**: Automatically increments dates and updates details
- **Customize**: Edit the duplicated event as needed

#### Event Status Management
- **Draft**: Event created but not visible to users
- **Active**: Event live and accepting registrations
- **Closed**: Registration closed, event upcoming
- **Completed**: Event finished, results can be added
- **Cancelled**: Event cancelled (participants notified)

### Event Statistics

Monitor event performance:
- **Registration Count**: Current vs. maximum capacity
- **Registration Rate**: Registrations per day
- **Participant Demographics**: Age groups, locations
- **Revenue Tracking**: If applicable

## 👥 Participant Management

### Viewing Participants

1. **Select Event**: Choose event from events list
2. **View Participants**: Click "View Participants" or participant count
3. **Participant List**: See all registered participants with details

### Participant Information

Each participant record shows:
- **Personal Details**: Name, email, contact information
- **Registration Info**: Registration date, status
- **Bib Number**: Assigned race number
- **Results**: Finish time, position (when event completed)

### Managing Participants

#### Bib Number Assignment
- **Automatic Assignment**: System assigns next available number
- **Manual Assignment**: Edit bib number if needed
- **Bulk Assignment**: Assign sequential numbers to multiple participants

#### Adding Results
1. **Event Completion**: Change event status to "Completed"
2. **Input Results**: Add finish times for participants
3. **Position Calculation**: System automatically calculates positions
4. **Bulk Import**: Upload results via CSV (if available)

#### Result Management
- **Edit Finish Times**: Click on time to edit
- **Update Positions**: Positions recalculate automatically
- **Handle DNF**: Mark participants who didn't finish
- **Verify Results**: Double-check before finalizing

### Participant Actions

**Individual Actions:**
- Edit participant details
- Assign/change bib numbers  
- Add/edit results
- Remove registration (if needed)

**Bulk Actions:**
- Export participant list
- Assign sequential bib numbers
- Import results from CSV
- Send notifications to groups

## 📊 Results and Analytics

### Managing Event Results

#### Inputting Results
1. **Complete Event**: Set event status to "Completed"
2. **Access Participants**: Go to event participant list
3. **Add Times**: Click finish time field to add/edit
4. **Auto-Calculate**: Positions update automatically
5. **Save Results**: Confirm all entries

#### Result Validation
- **Time Format**: Ensure proper time format (HH:MM:SS or MM:SS)
- **Position Logic**: Verify positions match finish times
- **Missing Results**: Handle DNF (Did Not Finish) participants
- **Duplicate Check**: Ensure no duplicate positions

### Analytics Dashboard

Monitor performance with:
- **Event Metrics**: Registration rates, completion rates
- **Participant Analytics**: Demographics, repeat participants  
- **Performance Data**: Average finish times, records
- **Growth Tracking**: Event popularity trends

### Reporting Features

Generate reports for:
- **Event Summary**: Complete event statistics
- **Participant Lists**: Registered and completed participants
- **Results Export**: Downloadable results in various formats
- **Financial Reports**: Revenue and registration fees (if applicable)

## 🏆 Certificate Management

### Certificate System Overview

The RunDay platform automatically generates certificates for event participants:

**Automatic Generation:**
- Participants can generate their own certificates after event completion
- Certificates include personal details, event info, and results
- Professional PDF format with performance-based styling

**Certificate Features:**
- **Winner Badge**: For 1st place finishers
- **Podium Badge**: For 2nd-3rd place finishers  
- **Finisher Certificate**: For all other participants
- **Event Branding**: Includes event and RunDay branding
- **Secure Storage**: Certificates stored in user accounts

### Managing Certificates

**Admin Responsibilities:**
1. **Complete Event Results**: Ensure all results are entered accurately
2. **Verify Positions**: Double-check winner and podium positions
3. **Enable Certificate Generation**: Certificates auto-enabled when results added
4. **Monitor Usage**: Track certificate generation in analytics

**Certificate Troubleshooting:**
- **Missing Certificates**: Ensure participant has complete results
- **Wrong Performance Badge**: Verify participant position is correct
- **Generation Issues**: Check that event status is "Completed"
